### Step 1 · Terminology (15 min, no page-budget risk)

- `main.tex:651` — Table 1's caption `\textbf{Gate S: what is left...}` → `\textbf{What is left
  when one model writes both classes.}` (This table is deleted at Step 4; do the rename anyway
  so the appendix pass is mechanical.)
- `main.tex:872, 942, 984` — "Gate S" → "the same-generator control" / "the same-generator arm".
- `main.tex:689` — `\textbf{A zero-shot monitor is inflated the same way.}` →
  **`\textbf{The same inflation reaches an LLM monitor.}` We put a monitor prompt to the model
  that wrote both classes — an untrusted monitor in this field's sense, not a trusted one.**
  Reason: in AI control "trusted" is a threat-model claim (weaker, or propensity
  well-characterised), never a quality claim. A frontier model scoring its own output is the
  collusion-prone *untrusted monitoring* case. Naming it correctly is both more honest and
  **strictly stronger for the paper** — a self-monitor is the most favourable case for the
  benchmark and it still deflates.
- `main.tex:481` — same fix in the abstract: "A zero-shot monitor is inflated the same way" →
  "An LLM monitor is inflated the same way".

### Step 5 · The contribution, stated as a construction (25 min) · **needs a build**

Two edits, and this is the one that answers *how does this advance control research*.

**a. `main.tex:533–540`, contribution (ii).** Currently reads as a measurement. Make it the
artifact:

> (ii)~**a same-generator construction for stored-pair benchmarks** — both classes written by
> one model under one prompt framing and verified by one harness — **and the corpus that
> implements it**, run on two generators, attributing between a third and nine-tenths of the
> separability to authorship and most of the remainder to the attack prompt's framing, with a
> negative result on the way: regenerating one half of a stored pair swaps the confound rather
> than removing it;

**b. §5 Recommendation 1.** Promote from a "should" to a named norm with its precedent:

> 1. **Generate both rollouts from one model under one prompt framing, and verify both with one
>    harness.** If the attack class is model-written, the honest class must be too; regenerating
>    only one side substitutes one authorship gap for another. Matched construction is
>    precedented in AI-generated-code detection — CodeMirage conditions generation on the human
>    sample's line and character count and forces regeneration on failure — but is applied
>    inconsistently even there, and we are not aware of it being applied to backdoor detection.

**The limit that must stay.** Do **not** let this drift into "a replacement benchmark." Our
attack class is 97.75% inert (14 of 623 Sonnet draws fire, 2 of 611 Haiku), because 52.0% of
test-passing draws reuse a public test input as their trigger. The defensible claim is *the
construction, a reference corpus, and ρ* — which is strong — not *a drop-in monitoring
benchmark*, which the firing rate will not support. The strict rows and the trigger-yield
explanation stay exactly where they are.
