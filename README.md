## The claim, in one paragraph

The stored honest/attack pairs that open trusted-monitoring results are trained, selected and ranked
on are **human-written versus LLM-written**. Honest solutions in `RoganInglis/apps-control-arena` come
from `codeparrot/apps` — no model is ever called; every backdoor is written by one of ten named LLMs.
On the field's own filtered, comment-stripped split, a bag-of-words classifier that cannot read a
backdoor reaches **AUROC 0.806 — above 20 of the 24 monitors ranked there** (median 0.609), a
classifier that reads **no code at all** reaches **0.772**, above 20 (0.7163 on a single held-out
slice, above 18 — state the protocol with the count), and the bag-of-words signal is
as strong on **inert** backdoors (0.954 pairwise) as on working ones (0.979). A monitor validated on
that corpus has been validated on a discrimination it will never face in deployment, where the
untrusted model writes both classes.

Five same-generator ControlArena agentic settings, where no authorship confound is possible, carry a
**second, structural** floor and supply the negative control for free.

**Both directions of the decisive control are a paper** (see [`PLAN.md`](PLAN.md) — Gate S):

- the bag-of-words signal collapses when honest code is regenerated by the attack model → **authorship**;
  the benchmark as stored measures who wrote the code. Title stands.
- it does not collapse → **content**; these backdoors are separable by surface features regardless of
  author, and LLM monitors are underperforming a linear model on them. New title, same figures, same
  recommendations.

## What the paper is *not*

Four sentences that were in the round-16 framing and are **dead**. Do not write any of them.

1. ~~"Nobody has run a trivial baseline."~~ `anik-jha/challenger-panels` ships `--leak-check` with two
   of them, and its README says *"Stripping is mandatory, not cosmetic."* **Credit it in paragraph one.**
2. ~~"The metadata floor is above the published monitor."~~ The "published monitor at 0.64" never
   existed — the DSPy tutorial reports 69% *pairwise accuracy* on a *matched* protocol where the
   metadata floor is exactly 0.500. Compare only on Koran's split, against Jha's per-item scores.
3. ~~"No control paper reports a construct-validity check on APPS backdoors."~~ The field filters to
   working honest + working backdoors, strips comments, and says why — `2605.15377` §4.1,
   `2608.16190` §2, `2602.10153`, `2506.05296` §2.3 + App. C.3. Claim the *quantification* and the
   *authorship reading*, nothing wider.
4. ~~"Longer code is the attack."~~ True at 0.826 pairwise on the raw artifact; **0.4726 — chance —
   on the filtered split**, which Jha published. It is a row in the what-preprocessing-leaves-behind
   table, not a finding.

Also not: a CoT-monitoring paper (`2607.09786` owns the instrument — one paragraph); not an AgentHarm
paper (**excluded on G2** — Andriushchenko authored it and is an EvoRobust invited speaker); not a
claim that live ControlArena evals are wrong (they generate both classes — the artifact is in
training, selecting and benchmarking monitors on **stored** pairs).
